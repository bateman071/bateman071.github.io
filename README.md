# Wastly AI

Industrial circular marketplace — **waste listing → Material DNA → matching → logistics → deal → contract → passport → carbon/ESG**.

**Live demo:** [https://bateman071.github.io/](https://bateman071.github.io/)

GitHub Pages is static hosting, so this public site runs the full SIH walkthrough **in the browser** (saved on this device). It is a demo, not a live registry or a legally binding exchange.

## What is estimated

- Carbon / ESG figures: **estimated — methodology dependent**. Wastly does not issue credits.
- Contracts: **AI drafts**. Not binding until both parties would approve in a real legal process.
- Matching and DNA in this Pages demo: deterministic catalogue (same logic as demo-mode on the full app).
